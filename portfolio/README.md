## 📌 About

This portfolio presents my work as an AI student and developer. It includes an introduction, technical skills, featured projects, resume information, and contact details.

The website is built with HTML, CSS, and vanilla JavaScript, with a focus on responsive design and interactive elements.

## ✨ Features

- **Responsive Layout:** Mobile-first design using Flexbox and CSS Grid.
- **Theme Toggle:** Switch between light and dark themes.
- **Theme Persistence:** Saves the selected theme and respects system preferences.
- **Navigation:** Smooth scrolling with a responsive hamburger menu.
- **Project Details:** Interactive project popups using the native HTML `<dialog>` element.
- **Semantic HTML:** Structured markup with keyboard-friendly focus styles.
- **Featured Projects:** Project information and details managed through JavaScript.
- **Contact Section:** Includes GitHub profile information.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic elements |
| CSS3 | Styling, Flexbox, Grid, and responsive design |
| JavaScript | Theme switching, navigation, and project modals |
| HTML Dialog API | Project detail popups |
| localStorage | Theme preference persistence |

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/AbdulRehmanYasir/Datheon_Full_Stack_Web_Development_Internship.git
```

**2. Open the portfolio folder**

```bash
cd Datheon_Full_Stack_Web_Development_Internship/portfolio
```

**3. Run locally**

Open `index.html` in your browser.

Alternatively, use a local development server:

```bash
npx serve .
```

## ⚙️ Customization

The portfolio content is managed in `script.js`.

- Update project details and descriptions.
- Edit the skills and technology list.
- Add your resume PDF when available.
- Add an email address to the contact section when ready.

## 🌐 Deployment

The portfolio can be deployed using:

**GitHub Pages**
1. Push the project to a public GitHub repository.
2. Open repository Settings → Pages.
3. Select **Deploy from a branch**.
4. Choose `main` and the project root folder.

**Other platforms:** Vercel and Netlify also support this static project without a build command.
